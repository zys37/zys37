# 🎵 Real-Time Lyrics Display 📟

<p align="center">
  <img width="512" alt="Raspberry Pi Pico displaying lyrics on OLED" src="https://github.com/user-attachments/assets/7f588ec2-37ea-4f8f-adda-c64d85277220" />
</p>

A hardware-software integration project that fetches and displays synchronized song lyrics in real-time. An asynchronous Python script running on Windows detects the currently playing track (via Spotify, YouTube, etc.), fetches synced LRC lyrics from an API, and streams them over a USB serial connection. A Raspberry Pi Pico H running MicroPython processes the incoming stream and drives an I2C OLED screen to display the current line synced with the music.

**Tech stack:** Python | MicroPython | Raspberry Pi Pico | Asyncio | Serial Communication | I2C
